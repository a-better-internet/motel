# Low Desert Engine: the field guide's source

`../Low-Desert-Engine-Guide.pdf` is built from the HTML in `src/`. The text
quotes the game's source, so when the engine changes, change the guide with it.

## Rebuilding the PDF

1. **Screenshots.** The guide's pictures are rendered by the game itself.
   Copy `shots/gshots.js` and `shots/h.js` into the probe harness directory
   (the one `sync.sh` builds, with `test.html` and a local `three.min.js`; see
   the end of `js/README.md`), make an `out/` folder there, and run each shot
   list:

       node gshots.js g1.json && node gshots.js g2.json && node gshots.js g3.json
       node gshots.js g4.json 1020 1320        # the portrait cover

   The first shot of every run is a dummy; the first frame is sometimes wrong.
   Point `SHOTS` at that `out/` folder when you run `build.py`. The texture
   swatches (`img/sw_*.jpg`) are `TEX[name].image.toDataURL()` written to
   PNG, tiled 2 × 2 when the map is 256 px or smaller, and scaled to 220 px.
2. **Fonts.** Oswald, Source Serif 4 and JetBrains Mono, as latin `woff2` files
   in `fonts/`, with a `fonts/fonts.css` whose `url()`s are relative to that
   folder.
3. **Build.** `python3 build.py` writes `guide.html` and `cover.html` (and the
   day/night chart, computed from the same formulas as `DayNight.tick()`).
   `node pdf.js` prints both with Chromium (the cover without a footer), and
   `python3 merge.py` (PyMuPDF) joins them into the finished PDF.

The images and fonts are not committed; they come to about 3.6 MB and are
regenerated by the steps above.
