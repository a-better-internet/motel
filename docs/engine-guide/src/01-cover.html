What is in here

The Low Desert Motel started as one HTML file and grew into a Route 66 motel, a desert with seven landmarks, a diner, a speakeasy forty feet under the ground, an auditorium, an ice rink and a 1950s living room seen through observation glass. Almost none of the code behind those places is about motels. It is a small, general engine for walkable first-person worlds. This guide pulls that engine apart so it can be handed to someone, or to another AI, and used to build something else entirely.

How to read the numbers

Units are metres, seconds and radians. y is up. At yaw 0 the camera looks down −z, which the compass calls north, so +x is east and +z is south. Every number quoted here is the one in the game's source, not an idealised version of it. Where the source and good practice disagree, the guide says so.
