Chapter one

The engine at a glance

A hand-rolled first-person engine on three.js r128. It has no bundler, no modules, no build step and no asset files: open index.html by double-clicking it and the whole world is generated in the browser. Every texture is drawn on a canvas at load time, every static object is merged into a handful of meshes, and the simulation runs at a fixed 60 steps a second.

How it is put together

The page loads 29 classic <script> tags in order. They share one global scope, so a const declared in an early file is visible to every later one, exactly as if it were one long file. The numbering on the file names is the load order, and nothing reorders itself.

Rule · Order is load-bearing

A function declaration only hoists within its own script. If a file's top-level code calls a function declared in a later file, the page throws on load. Calling a later file's function from inside a function body is fine, because by the time anything is called every script has run. That is why the sign helpers live in 02-textures.js: half the world raises a sign before 12-signage.js loads. Any registry that several files push into (GLOW, ANIM, LAMPS, DOORS) must be declared before all of them.

One frame

The simulation and the picture run on separate clocks. Physics, walking and driving advance in fixed 1/60 s steps from an accumulator, so the game behaves the same at 30 fps as at 144. Anything drawn from simulated state (the car, the drone) is drawn between its last two steps using stepAlpha, so motion stays smooth whatever the display rate.

function frame(){
  requestAnimationFrame(frame);
  let delta = Math.min(now - last, 0.1);        // a stalled tab cannot fling you through a wall
  acc += delta; let guard = 0;
  while(acc >= STEP && guard++ < 6){            // STEP = 1/60
    if(driving) driving.veh.savePrev();         // one step of history, for drawing between steps
    fixedUpdate(STEP);
    acc -= STEP;
  }
  stepAlpha = clamp(acc/STEP, 0, 1);
  // ...camera, day/night, lamps, emissives, HUD...
  renderer.render(scene, camera);
}

Five ideas the whole engine rests on

  1. Paint, don't light, the colour. Every surface carries a hex you chose, stored as a vertex colour. The lighting shades it but never decides it, and a tone-mapping shoulder stops bright paint clipping to white.
  2. Few real lights, many fake ones. One sun, twelve point lights reassigned every frame to the lamps nearest the camera, and emissive or unlit materials for everything else that glows.
  3. Merge everything that does not move. Geometry is pushed into named buckets by material, and each bucket bakes into one mesh. A world of tens of thousands of pieces draws in a few hundred calls.
  4. Collision is boxes and floors, not meshes. Axis-aligned boxes with a vertical span block you, and a separate list of flat plates and ramps says what you stand on. Geometry and collision are authored side by side and must agree.
  5. Everything is generated. Textures are drawn on canvases, terrain is a function, and furniture is primitives. The page needs nothing but three.js. Real pictures are optional overrides.
