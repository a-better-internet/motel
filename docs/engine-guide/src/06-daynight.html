Chapter five

The day/night cycle

One number, the time of day, drives the sun, the moon, the sky, the stars, the fog, every lamp, every glowing surface, every lit sign, the pool, the headlights and the wildlife. Nothing else in the world knows what time it is; it only asks how dark it is.

The clock

const DayNight = { DUR: 414,                        // real seconds for 24 game hours
  state: { t: 0.478, ... },             // t ∈ [0,1); 0 is 06:00, so the game opens near 17:28
  setHour(h){ s.t = (((h - 6)/24) % 1 + 1) % 1; },
  nudge(d){ s.t = (s.t + d + 1) % 1; },
  tick(dt){ if(!s.paused) s.t = (s.t + dt/DUR) % 1;  ...  s.hour = (s.t*24 + 6) % 24; }
};

The player can jump to nightfall (N, 21:36) or midday (M, 12:30) and scrub time with [ and ] (about 29 game minutes a press). Before the player clicks start, the clock runs at a quarter speed behind the title card.

From the clock to the light

The sun travels a circle: ang = t × 2π, and its height is sunHeight = sin(ang), which is 0 at 06:00 and 18:00, 1 at noon and −1 at midnight. Every blend in the cycle is a smoothstep of that one value:

Where the sun is

sunDir.set(Math.cos(ang)*190, Math.max(14, Math.sin(ang)*190 + 6) - camY*0.3, 70).normalize();
// rises in +x (east), sets in −x (west), always tilted towards +z (south) by the 70
// never lower than 14 above the horizon as a light, so shadows never stretch to infinity
placeCelestial(sunDisc,  ang,  1, 70/190);     // sprites 1,800 m out along the same direction…
placeCelestial(moonDisc, ang, -1, 70/190);     // …and the moon exactly opposite

The sun disc is an additive sprite that grows from 320 to 580 units and shifts from #fff4d6 to #ff6f28 as it nears the horizon, fading out as it drops below. The moon fades in with nightAmount. Stars are three Points layers by magnitude, with colour temperatures from blue-white to orange and a Milky Way band, hung on a tilted pivot that turns with the hour, so the sky wheels overhead.

The palette

Every colour the cycle uses lives in one object, DayNight.P. To move this engine to a different climate (a grey northern coast, a green valley, an alien planet) this is the first thing to repaint.

Each frame paint() mixes the three sets by day, set and night weights and redraws a 16 × 256 canvas with seven stops (0, 0.19, 0.33, 0.42, 0.58, 0.72, 1.0). The canvas maps onto a 2,400 m sphere drawn inside-out around the camera, with fog and depth writing off. The horizon colour is also the fog colour and the clear colour, so the world's edge always dissolves into the sky.

Rules for the cycle
  • Ask how dark it is, never what time it is. Everything reads dark or nightAmount. Change the curve in one place and the whole world follows.
  • Twilight lingers. A desert dusk is a long warm band, not a switch. The set and twilight terms overlap the horizon on both sides so the change takes about an hour of game time, about 17 real seconds.
  • Turn off shadows you cannot see. Below a sun height of 0.04 the key stops casting; the moon's shadows would be all acne and no shape.
  • Give the night a real moon. A key of about 0.38 in pale blue is enough for cliffs and strata to keep reading across the valley. A token moon gives you a black screen with lit windows in it.
  • Haze is darker than the night sky. Otherwise distant mountains wash out into the fog instead of standing against it.
